Репозиторий с последними версиями отчётов и планов MS Project.

## Состав

### `Shisterin/` — мобильный интернет-банк («УП_Шистерин»)
- `УП_Шистерин.docx` — отчёт (Word)
- `УП_Шистерин.doc` — отчёт (Word 97-2003)
- `УП_Шистерин.pdf` — отчёт (PDF)
- `УП_Шистерин.mpp` — основной план MS Project
- `УП_Шистерин_эксперимент.mpp` — копия плана для экспериментов
- `Скриншоты/` — иллюстрации отчёта (43 шт.)
- `_build/` — скрипты сборки отчёта и пересъёмки скриншотов

### `Matvih/` — нейросеть распознавания дефектов («УП_Матвих»)
- `УП_Матвих.docx` — отчёт (Word)
- `УП_Матвих.doc` — отчёт (Word 97-2003)

- `УП_Матвих.mpp` — основной план MS Project
- `УП_Матвих_эксперимент.mpp` — копия плана для экспериментов
- `Схема_экспертизы_проекта.docx` — схема экспертизы
