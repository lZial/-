**Тема: «Разработка нейросети для распознавания дефектов на производстве»**  
Выполнил: Матвих, группа 9ИС-323 (см. `_build/config.json`).

Подготовлен файл плана (`.mpp`) и отчёт в форматах Word/PDF.

## Как пересобрать

```powershell
cd D:\UP_NeuralDefects\_build
python build_project.py          # базовый .mpp (без серии совещаний)
python create_recurring.py       # добавить серию совещаний в текущий .mpp
python rebuild_experiment.py     # пересобрать эксперимент из актуальной базы
python make_report2_part2.py     # собрать .docx
python finalize_doc.py           # обновить оглавление, выгрузить .doc/.pdf
```

Зависимости: Windows + MS Project (COM), Python с `pywin32`, `python-docx`, `Pillow`, `pywinauto`.

> Файлы `УП_*.mpp/.doc/.docx/.pdf` формируются автоматически. Имя берётся из `_build/config.json`.
> Визуальные скриншоты `Скриншоты/` после сдвига дат/пересборки требуют повторной съёмки (`shoot*.py`, `shoot_reports.py`, `_crop_reports.py`) в стабильной сессии MS Project UI.
